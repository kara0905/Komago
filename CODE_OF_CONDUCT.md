# Code de conduite

Komago veut être un projet accueillant pour toutes et tous, quels que soient l'âge, l'apparence, le handicap, l'origine, l'identité ou l'expression de genre, l'orientation sexuelle, la religion, le niveau d'expérience ou la langue.

## Ce que nous attendons

- Être respectueux et bienveillant, y compris dans le désaccord.
- Critiquer des idées ou du code, jamais des personnes.
- Accepter les retours avec ouverture et reconnaître ses erreurs.
- Garder à l'esprit que les contributeurs sont souvent des bénévoles.

## Ce qui n'est pas acceptable

- Insultes, moqueries, propos discriminatoires ou à caractère sexuel.
- Harcèlement, public ou privé, et intimidation.
- Publication d'informations personnelles d'autrui sans son accord.
- Partage de contenus protégés par le droit d'auteur obtenus illégalement.

## Application

Ce code s'applique aux issues, pull requests, discussions et à tout espace lié au projet. Les mainteneurs peuvent modifier ou supprimer les messages contraires à ces règles, et exclure temporairement ou définitivement une personne qui les enfreint.

Pour signaler un comportement, contactez le mainteneur en privé via son profil GitHub ([@kara0905](https://github.com/kara0905)). Les signalements sont traités avec discrétion.

Ce code s'inspire du [Contributor Covenant](https://www.contributor-covenant.org).
